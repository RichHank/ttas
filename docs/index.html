Method

The GitHub Pages version is a static portfolio snapshot. The full Dash application, pipeline, Docker files, and reproducible local cache workflow are in the repository.

Manifold

Each property-month is embedded in a twelve-dimensional feature lattice covering price, rent pressure, velocity, tax, schools, centrality, amenities, risk, mobility, and DTI.

Filtration

The tri-parameter filtration tracks affordability, local density, and opportunity. Euler surfaces and signed barcode summaries expose the changing shape of the market.

Decision

A household biography restricts the market to affordable homes. TTAS integrates the persistence-landscape difference to form the buy signal S(B).
